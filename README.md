# NICHIYA (日夜)
### High-End Select Shop — Where Night Meets Day

**NICHIYA**는 ‘밤낮(日夜)’이라는 이름처럼,  
시간의 경계를 넘어 언제 어디서나 즐길 수 있는 하이엔드 온라인 편집숍입니다.  
세련된 감각과 품격 있는 브랜드를 엄선하여,  
하루의 모든 순간에 어울리는 라이프스타일을 제안합니다.

> **밤에도, 낮에도 — 당신의 취향은 멈추지 않습니다.**

### 🛍 프로젝트 개요
**BNK_MarketProject_Be**  
NICHIYA는 Spring Boot 기반의 전자상거래 플랫폼으로,  
사용자가 밤낮없이 고품질 제품을 탐색하고 구매할 수 있도록 설계되었습니다.  
관리자(Admin)와 사용자(User) 페이지를 분리하여  
효율적인 상품 관리와 유연한 UI/UX 경험을 제공합니다.

---

### ⚙️ 주요 기술 스택
- **Backend:** Spring Boot 3.x, Java 17, MyBatis, QueryDSL  
- **Database:** Oracle XE (XEPDB1)  
- **Frontend:** Thymeleaf, JavaScript, CSS  
- **CI/CD:** GitHub Actions, AWS EC2

### ✨ 내가 한 업무 (Role)

팀장 (Project Leader & Backend Developer)

1. 프로젝트 기획 주도

- NICHIYA 서비스 콘셉트·기능 요구사항 도출

- 사용자/관리자 페이지 구조 기획 및 전체 UX 흐름 정의
  

2. 디자인 참여

- 메인 화면 레이아웃, 상품 카드 구성, 컬러·톤앤매너 방향성 제안

- 시그니처 페이지(메인·상품 상세) 디자인 컨셉 초안 제작
  

3. DB 설계 총괄

- ERD 작성 및 상품/주문/회원/이미지 테이블 구조 설계

- 실제 운영 프로세스를 고려한 관계 설정 및 컬럼 구조 확립
  

4. 업무 분배 및 일정 관리

- 개발 일정표 작성, 기능 단위로 팀원 업무 분배

- 매주 스프린트 진행 상황 점검 및 코드 리뷰
  

5. AWS 배포 환경 구축

- EC2 기반 서버 환경 구성

- Jenkins/GitHub Actions 기반 자동 배포 파이프라인 구성 참여
  

6. 핵심 화면 개발

- 메인 화면 설계 및 기능 구현 (메인 배너, 카테고리, 실시간 상품 노출)

- 마이페이지 기능 개발 참여 (주문 내역, 회원 정보 조회 등)
  

7. 프로모션 시연 영상 제작

- 서비스 전체 흐름을 담은 프로모션 영상 기획·촬영·편집
  

8. 문서 작업 전담

- 요구사항 정의서, API 문서, 발표 자료, 회의록 등 프로젝트 문서 작성
